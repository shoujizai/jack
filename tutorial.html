📚 入门教程

从零开始，手把手教你安装和使用大气层系统

什么是大气层？

大气层（Atmosphere）是一款开源的Switch自制系统固件，让你可以在Switch上运行自制软件和游戏备份。

大气层是由开发者CTCaer等人维护的开源项目，是目前最流行、最稳定的Switch自制系统。它支持所有Switch机型（除OLED版需要特定芯片外），可以运行NSP/XCI格式的游戏、安装插件、主题等。

💡 小贴士

大气层是目前最安全的自制系统方案，支持虚拟系统(EMUMMC)，可以在不影响原机系统的情况下运行。

准备工作

在开始之前，请确保你已准备好以下物品：

  • 一台可破解的Switch主机 - 检查序列号确认是否可破解
  • 一张容量至少64GB的TF卡 - 推荐128GB以上，高速卡更佳
  • 一张TF卡读卡器 - 用于传输文件
  • 稳定的网络连接 - 用于下载必要文件
  • RCM注入工具 - 如注入器或安卓手机

⚠️ 重要提示

请确保你的Switch是可破解版本！一般来说，2018年7月之前生产的机器大多可破解。可以在网上搜索"Switch序列号查询"来确认。

安装步骤

第1步：备份原机NAND

将Switch进入RCM模式，使用工具备份原始NAND，这是最重要的安全措施。NAND备份可以在出现问题时恢复原机状态。

第2步：制作启动卡

将TF卡格式化为FAT32格式，下载大气层整合包，解压到TF卡根目录。确保文件结构正确。

第3步：注入启动

使用注入器或手机注入hekate启动文件，进入hekate菜单。首次启动需要注入payload文件。

第4步：启动系统

在hekate中选择"Launch" -> "CFW (EMUMMC)"启动大气层系统。建议每次都通过虚拟系统启动。

第5步：初始设置

设置语言、时区、网络等基本配置。建议关闭自动更新，避免系统自动升级导致不兼容。

第6步：安装必要软件

通过DBI或Awoo Installer安装必要的自制软件，如游戏安装器、文件管理器等。

注意事项

⚠️ 重要警告

  • 切勿连接官方任天堂服务器 - 可能导致ban机
  • 定期备份EMUMMC - 防止系统损坏无法恢复
  • 不要随意更新系统版本 - 等待大气层更新支持后再更新
  • 使用DNS屏蔽 - 防止意外连接任天堂服务器

💡 建议设置

  • 设置 -> 互联网 -> 互联网设置 -> 选择网络 -> 更改设置 -> DNS设置 -> 手动输入屏蔽DNS
  • 设置 -> 主机 -> 自动更新软件 -> 关闭
  • 定期使用hekate备份EMUMMC
