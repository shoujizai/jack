安装游戏

了解各种游戏格式，掌握多种安装方法，轻松管理你的游戏库

游戏下载分类介绍

分类名称 说明
本体 游戏主体文件，包含游戏的基础内容，是运行游戏的必需文件
Update 升级包 游戏更新补丁，修复bug、优化性能、添加新功能，建议安装最新版本
DLC 下载内容扩展包，包含额外剧情、角色、道具、关卡等付费内容
整合 包含本体+升级包+DLC的完整版本，不需要和分体下载重复，通常为XCI整合，签名稳定性不如分体下载。

💡 下载格式选择建议

推荐使用 NSP 原版格式，兼容性最好，安装最方便。XCI 整合格式有一些升级后会失效。

安装方法

方法一：SJZ更新(桌面打开)（炫酷，方便）

SJZ更新是手机仔制做的一个在switch上一站式APP

  1. 选择MTP工具——点击mtp启动—用数据线连接电脑(按y键可以打开控制台)
  2. 打开我的电脑,选择nintendo switch盘，打开5号盘(5.install SDcard)
  3. 按提示把游戏文件或者文件夹拉到文件夹(游戏格式要正确,不可以使用zip,rar其他格式的压缩包)
  4. 查看进度条，显示安装成功即可，无需其他操作。桌面便可生成游戏

方法二：DBI（权限模式）

switch小程序中的神

  1. 按住R键不要放，直到用a键打开一个游戏进入小程序界面再松开R键
  2. 选择打开DBI（此时DPI的背景为黑色，不用管弹出的提示）
  3. 选择运行MTP程序或者按X键，会提示你用数据线连接电脑
  4. 打开我的电脑,选择switch盘，打开5号盘(5.SD card install)
  5. 按提示把游戏文件或者文件夹拉到文件夹(游戏格式要正确,不可以使用zip,rar其他格式的压缩包)
  6. 查看进度条，显示安装成功即可，无需其他操作。桌面便可生成游戏

方法三：U盘安装

将游戏文件拖拽到U盘上，插入Switch，用DBI安装。

  1. 按住R键不要放，直到用a键打开一个游戏进入小程序界面再松开R键
  2. 选择打开DBI（此时DPI的背景为黑色，不用管弹出的提示）
  3. 插上U盘稍等会弹出浏览USB驱动器，选择打开
  4. 找到你的游戏文件并安装，选择安装位置sd,进行安装(只能安装文件，不可以选择文件夹)
  5. 查看进度条，显示安装成功即可，无需其他操作。桌面便可生成游戏
