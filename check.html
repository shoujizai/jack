说明

健康：/api/health 返回 200，且 db 为 connected，tables 里能看到 users、comments、sessions。

接口 404：说明 /api/* 请求没有交到 Worker，而是被静态资源吞掉了 —— 需要确认 wrangler.toml 里有 main 入口，或改用 Worker 路由。

db 为 error：说明 Worker 里拿不到 D1 数据库，需要在 Worker 的 Settings → Bindings 里绑定 D1，变量名必须是 DB。

tables 为空：说明数据库连上了但没建表，需要在 D1 控制台执行 api/schema.sql。
